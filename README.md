# DIO-METASPOITABLE2
teste de bruteforce usando kali e medusa em ambiente virtual

a atividade consiste em utilizar métodos descritos durante as aulas para implementar ataques de força bruta, usando wordlist e buscando vulnerabilidades em formulários na web. 
Houveram ferramentas essenciais para a verificação de falhas na maquina virtual Metasploitable 2, incluindo enum4linux para verificar os usuários, nmap para verificar quais
portas estavam abertas
